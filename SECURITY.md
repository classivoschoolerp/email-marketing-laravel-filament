# Security policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email **info@classivoerp.com** with the subject line "Security report". Please include:

- the affected version or commit
- steps to reproduce, or a proof of concept
- the impact you expect

We aim to acknowledge reports within 3 working days and to agree on a disclosure date with you.

## Supported versions

Security fixes go into the latest release on the `main` branch.
