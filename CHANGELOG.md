# Changelog

## v1.0.0 — first public release

- First open-source release under the MIT License.
- Email marketing core for a single company: lists, subscribers, custom fields, segments,
  import/export, campaigns, the GrapesJS builder and templates, delivery servers, sending
  domains with DKIM, bounce processing, reports, signup forms, blacklist, suppression and
  unsubscribe handling.
- Admin panel and customer workspace panel.
